# AI OS Shell & AI Engineering Studio

A floating desktop AI companion and AI Engineering Studio built with **Electron + React + Vite + TailwindCSS + Framer Motion + Zustand**.

---

## ⚡ The AI Engineering Studio

A futuristic **AI Engineering Studio** that morphs directly out of the floating capsule with zero page refreshes. Designed specifically for AI system engineering — completely free of traditional IDE layouts (no standard VS Code sidebar/editor appearance).

### Included Modules & Features

| Module | Feature Set |
|---|---|
| ⚡ **AI Terminal** | Interactive neural shell with command execution, live output streams, PID/RAM telemetry, and directive prompt input. |
| 💬 **Conversation** | Multi-agent dialogue thread, agent thought process inspector, and active instruction input. |
| 📄 **Generated Files** | Code diff viewer (`+`/`-`), file status badges (`+14 lines`, `+180 lines`), and interactive file tree. |
| 🔍 **Research** | Neural research synthesis card, web citation chips with relevance percentages (`arxiv.org 99%`, `electronjs.org 96%`). |
| 🎯 **Tasks** | Autonomous agent execution pipeline with completion percentage meter and interactive task toggles. |
| ⏳ **Timeline** | Time travel revision scrubber, prompt snapshot history, and git commit hash tracking. |
| 💎 **Artifacts** | Rich architecture specifications and interactive SVG flow diagram cards. |
| 🧠 **Memory** | Vector database embedding inspector, project rules, and long-term context recall list. |
| 📡 **Logs** | Real-time system event stream, IPC message tracer, and 140 t/s telemetry monitor. |

---

## 🔮 The Floating Capsule

- Compact `324×56px` dark glassmorphic pill floating above the Windows taskbar.
- **Plasma Orb**: Conic-gradient rotation with pulsing inner core.
- **Voice-First Interface**: Audio visualizer with Web Audio API frequency bars, partial/final transcription, and interruption controls.
- **Spring Physics**: Morphing animations powered by Framer Motion (`stiffness: 380, damping: 28`).
